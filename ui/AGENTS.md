# FastAPI_New 项目指令

以下约定适用于 `ui/` 下的前端开发。

## 组件库与布局

- 项目使用 Vue 3 和 Ant Design Vue 4.2.6。在需要组件的 `.vue` 文件中按需导入，并通过 `components` 局部注册。禁止在应用入口全量注册组件库。
- 界面优先复用 Ant Design Vue 提供的组件。布局优先选用 `Layout`、`Row`、`Col` 和 `Space`，表单、表格、弹窗等交互优先使用已有组件。通过组件属性和插槽扩展展示，将主题色、圆角等公共视觉规则集中在 `ConfigProvider` 的主题配置中。
- 原生 HTML、自定义 CSS 和直接 DOM 操作仅用于补足语义、可访问性或组件库无法满足的需求。只有现有组件和项目内的实现无法合理满足明确需求时，才引入其他 UI 组件库。

## Vue 编码方式

- 在 Vue 3 中采用 Vue 2 风格的 Options API 编写单文件组件。使用 `export default` 和 `components`、`props`、`emits`、`data()`、`computed`、`methods` 等选项组织代码。
- 使用 Vue 的响应式状态、模板绑定和组件事件实现交互。派生状态优先使用 `computed`，业务操作放在命名明确的 `methods` 中。

## 代码组织与可维护性

- 按职责组织代码。页面编排业务流程，可复用的界面封装为组件，接口调用集中在 API 模块。使用体现业务含义的命名，保持函数职责单一，优先复用已有实现。
- 有明确复用需求时，将无状态逻辑提取为工具函数。需要封装独立状态或生命周期时，可使用职责明确的工具类。保持实现简洁，抽象层级以当前需求为准。
